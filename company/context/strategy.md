# strategy.md｜X戦略・マネタイズ方針

> コンセプトの根拠は `concept-research.md` を参照。毎月初めにKPIを更新すること。

## 発信ジャンル
- メインジャンル：AI活用×副業の検証実録（Claude Code Company運用の実録）
- サブジャンル：非エンジニア向けAIツール解説
- 交流・いいね・引用の対象ジャンル（社員1〜4の選定基準）：
  - AI活用・Claude/ChatGPT・副業・SNS運用・フリーランス
  - 特に「AIを学び始めたばかりの人」「検証・実録系の発信者」を優先

## フェーズ戦略（現在：フェーズ1）
| フェーズ | 目標 | 方針 |
|---------|------|------|
| 1. 信頼構築（0〜3ヶ月） | フォロワー1,000 | 検証実録＋無料note。**売らない** |
| 2. 初マネタイズ（3〜6ヶ月） | note初売上 | 検証で溜まった手順書を1,000〜3,000円で販売 |
| 3. 導線強化（6ヶ月〜） | LINE登録100人 | LINE特典→ステップ配信→上位商品 |

## 導線設計
- フェーズ1：プロフィール → 無料note（検証まとめ）→ フォロー定着
- フェーズ2以降：プロフィール → LINE登録（特典：セットアップ手順書）→ note販売
- 商品（フェーズ2で作成予定）：
  - 「非エンジニアのためのClaude Code Company構築手順書」1,980円目安
    （実用ノウハウ系noteの市場平均価格は約1,800円）

## 投稿方針
- 通常投稿：1日3〜5本
  - 内訳目安：検証実録・数字報告 1〜2本／AI活用Tips 1〜2本／問いかけ・交流 1本
- 記事ポスト（長文）：週2〜3本（滞在時間がアルゴリズム評価に直結するため必須）
- 週次で「今週のAI会社 成果報告」を固定フォーマットで投稿（連載化してフォローする理由を作る）
- 投稿の優先順位：
  1. 検証実録（数字・スクショ付き）
  2. AI活用の手順解説
  3. 問いかけ・体験談

## 今月のKPI（2026年7月）
- フォロワー目標：まず100人（0→100が最難関。交流：投稿＝5：5で動く）
- 投稿：毎日3本以上を継続
- 無料note：1本公開（Claude Code Company構築記）
- 売上目標：0円（フェーズ1のため売らない。信頼構築に全振り）

## 禁止事項（アカウント生存のため厳守）
- 稼いでいない段階で稼いだと言わない
- 宣伝リプ・便乗告知をしない（スパム判定→凍結リスク）
- 投稿・フォロー・いいねの実行は必ず社長が手動で行う

# コンセプトリサーチ｜裏垢（匿名）X運用（2026年7月時点）

## 市場リサーチの要点

### 1. 売れているジャンル（note有料コンテンツの成長率）
| ジャンル | 前年比成長率 | 備考 |
|---------|------------|------|
| AI活用 | +268% | 2026年最も勢いがある |
| SNS運用 | +258% | ただし「実績の証明」が必要 |
| 副業・在宅ワーク | +179% | 飽和気味。金額断言系はリスク |
| デザイン・動画 | +155% | スキル前提 |
- 実用ノウハウ系noteの平均価格：約1,800円

### 2. 2026年のXアルゴリズム
- リプライの往復＝いいねの約75倍の評価。「会話が生まれる投稿」が最優先で拡散される
- 滞在時間2分以上＝いいねの22倍。長文の記事ポストが有利
- フォロワー数よりコンテンツの有益性・専門性を評価
- 後発の小規模アカウントによる宣伝リプ・便乗告知はAIに即スパム判定される
  → 社員2（リプ周り）の「宣伝・誘導は絶対に含めない」ルールはアルゴリズム的にも正しい

### 3. 匿名（裏垢）運用との相性
- 顔出し・実名なしで成立するのは「実績・検証データで語れるジャンル」
- 匿名で「稼げます」と断言する系は信頼を得にくく、凍結・通報リスクも高い
- 匿名でも強いのは「過程を全部見せる実験・検証型」ポジション

## コンセプト候補3案

### 案A（推奨）：「AI社員に働かせて検証する匿名会社員」
- **一言コンセプト**：ラーメン好きの平凡な会社員が、AI社員7人の"会社"を作って副業を検証する実録
- **ポジション**：先生ではなく **実験者**。「稼げる」と断言せず、過程と数字（失敗含む）を全部見せる
- **強み**：
  - AI活用ジャンル（+268%）の波に乗れる
  - 今まさに構築したClaude Code Companyそのものがコンテンツになる（発信ネタに困らない）
  - 実績ゼロから始められる。検証の数字自体が実績になるので嘘をつく必要がない
  - 飽和している「断言型の稼げる系」との明確な差別化になる
- **マネタイズ**：検証実録・セットアップ手順書のnote（1,000〜3,000円）→ LINE → 上位商品
- **裏垢適性**：◎（顔・実名不要。数字とスクショで信頼を作れる）

### 案B：SNS運用・Xアルゴリズム攻略系
- 需要は大きい（+258%）が、「お前のフォロワー数は？」と実績を問われるジャンル。
- 後発・実績ゼロの匿名アカには入り口が厳しい。**案Aで伸びた後の2本目の柱として温存**。

### 案C：副業全般・稼げる系
- 最も飽和しており、匿名×金額断言は信頼されにくく通報・凍結リスクも最大。**非推奨**。

## 推奨コンセプト（案A）の設計

### アカウント設計
- 名義：ラーメン太郎（@x_ramentaro）
- キャラ：ラーメン好きの普通の会社員。すごい人ではなく「一歩先を行く実験台」
- 世界観：夜な夜なAI社員に指示を出して、翌朝の成果報告を楽しむ

### 発信の3本柱
1. **検証実録**（差別化の核）：AI会社運用の数字・成果・失敗を毎週報告
2. **AI活用の噛み砕き解説**：Claude Code等の手順を非エンジニア向けに翻訳
3. **問いかけ・交流**：アルゴリズムがリプ往復を最重視するため、答えやすい質問を1日1本

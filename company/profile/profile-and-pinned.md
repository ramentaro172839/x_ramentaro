### 案A（イチオシ・ゆるさと共感）
```
アラサーOL / 毎日ちゃんと頑張れない日もある🫠
仕事・お金・恋愛、ぜんぶ等身大でつぶやきます。
同じ気持ちの人とゆるく繋がれたら嬉しい。
無理しない、を大事に生きてます。
```

### 案B（本音・弱音より）
```
27歳、会社員。
すごくもないし、完璧でもないけど、毎日なんとか生きてる。
仕事の愚痴とお金の不安と、たまに恋の話。
「わかる」って思ったらフォローしてね☺️
```

### 案C（やわらかい・短め）
```
がんばりすぎないOLの本音メモ。
仕事・お金・恋愛、等身大でぽつぽつ。
夜にそっと繋がれる場所にしたい🌙
```

**業者感を消すコツ（全案共通）**
- 「発信」「有益」「毎日投稿」などのSNS運用ワードを入れない
- リンク・「詳しくはこちら」「登録して」を入れない（フェーズ1では特に）
- 絵文字は1〜2個まで。多すぎると宣伝アカっぽくなる
- 完璧な自己紹介にしない。少し隙・弱さを残すほうが人間味が出る

## 固定ポスト（自己紹介ポスト・3案）

### 案A（イチオシ・自己開示＋問いかけ）
```
はじめまして、ゆるりです。

アラサーのOLで、毎日ちゃんとしてるフリして
本当はけっこうギリギリで生きてます。

仕事のこと、お金のこと、恋愛のこと、
うまく言えない本音をここにぽつぽつ置いていきます。

同じような人、そっと手あげてくれたら嬉しい🙋‍♀️
```

### 案B（あるある共感で入る）
```
・日曜の夜がいちばん憂鬱
・給料日の3日後にはもうカツカツ
・恋愛より睡眠を優先しがち

こういうの全部「わかる」ってなる人のための場所を作りました。
がんばりすぎない20代の本音、置いていきます。
仲良くしてね☺️
```

### 案C（短くやわらかい）
```
毎日おつかれさまです、ゆるりです🌙

すごい人じゃないけど、
同じくらいの目線で「わかる」を分け合える場所にしたくて。

仕事・お金・恋愛、等身大でつぶやきます。
よかったら、ゆるく繋がってください。
```

**固定ポストのコツ**
- 1行目で名乗る＋弱さを1つ見せると一気に親近感が出る
- 最後は「繋がってね」で締める（フォローを押す背中を押す。でも営業しない）
- 「〜を発信します」より「〜を置いていきます」の方が自然でやわらかい
- ハッシュタグは付けない（固定ポストに付けると宣伝感が出る）

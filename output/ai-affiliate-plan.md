# AI×アフィリエイト リサーチ & 実行プラン

作成日: 2026-07-05
対象: @yuruto23 のリサーチと、初心者向けAI×アフィリエイト戦略の提案

---

## 1. @yuruto23 リサーチ結果

### 確認できたこと・できなかったこと

- X本体はログイン制限のため直接閲覧不可（403）。Yahoo!リアルタイム検索も取得不可
- 検索経由では「AI×アフィで月収1,500万〜2,000万」系の発信をしているアカウントという情報のみで、
  **収益の実在を裏付ける第三者情報は見つからなかった**
- 「AI×アフィリエイトで稼げる」という投稿からnote→LINE誘導される手口についての
  Yahoo!知恵袋の相談が検索でヒットしており、このジャンル自体が勧誘ファネルとして使われている

### この界隈のビジネスモデルの実態（重要）

「AI×アフィで月○千万」と発信するアカウントの収益構造は、ほとんどの場合こうなっている:

```
X で「稼げる」実績を発信（実績画像は自己申告）
  ↓
無料note / 無料LINE登録へ誘導
  ↓
Brain / note / Tips で情報商材を販売（1万〜30万円）
  ↓
さらに購入者が Brain の紹介機能（報酬率40〜50%）で同じ商材を拡散
```

つまり **「アフィリエイトで稼いだ」のではなく「アフィリエイトの稼ぎ方という商材を売って稼いだ」**
というケースが大半。Brainの紹介機能は構造的にマルチ商法に近く、高額商材×高率紹介の組み合わせは
特定商取引法の「連鎖販売取引」に該当するリスクも指摘されている。

### 結論

- この人の「月2,000万」を鵜呑みにして同じ道を追うのは推奨しない
- ただし「AIで制作コストを下げてアフィリエイトをやる」こと自体は真っ当な戦略で、再現性もある
- 現実的な目安: アフィリエイト実態調査では月1万円未満が過半数。月10万円で上位層、
  月100万円超はごく一部。**まず月1万→5万→10万の階段を設計するのが正しい**

## 2. 提案: 初心者向け AI×アフィリエイト戦略

### 基本方針

- 商材を「売る側」ではなく、真っ当な **ASP アフィリエイト**（広告主の商品を紹介して成果報酬）
- AIの役割は「量産」ではなく「制作スピードと品質の底上げ」
  （Google・noteともAI量産スパムの取り締まりを強化中。量産型は資産にならない）

### ステップ0: ジャンル選定（最初の1週間）

自分が体験談を語れるジャンルを1つに絞る。初心者向けの狙い目:

| ジャンル | 単価目安 | 難易度 | 備考 |
|---|---|---|---|
| AIツール紹介（ChatGPT/画像生成等のSaaS） | 数千円/件 | 中 | 自分が使った実体験を書ける |
| 転職・スキルアップ講座 | 5千〜2万円/件 | 中〜高 | 単価高いが競合強い |
| VPN・レンタルサーバー等 | 数千〜1万円/件 | 中 | 定番。比較記事と相性◎ |
| サブスク（動画・宅食など） | 数百〜数千円/件 | 低 | 成果は出やすいが単価低い |

※ 金融・医療・健康（YMYL）は初心者は避ける。専門性がないと検索で戦えない＋規制が厳しい。

### ステップ1: 土台づくり（1ヶ月目)

1. ASP登録（無料）: A8.net、もしもアフィリエイト、afb、Amazonアソシエイト、楽天アフィリエイト
2. WordPressブログ開設（レンタルサーバー月1,000円程度が唯一の初期費用）
3. X アカウント開設: ブログと同ジャンルで発信。プロフィール設計もAIと壁打ち

### ステップ2: AI活用コンテンツ制作（1〜3ヶ月目）

Claude / Claude Code の使いどころ:

- **キーワード調査の整理**: 検索意図の分類、記事構成案の生成
- **記事の下書き**: 構成→下書きをAIで作り、**体験談・スクショ・独自の検証結果を人間が足す**
  （ここをサボるとAI量産ゴミ記事になり、Googleにも読者にも刺さらない）
- **リライト・推敲**: 見出し改善、導入文のABパターン出し
- **X運用**: 記事の要点をポスト用に変換、リプライ案の生成
- **このリポジトリの使い方**: `src/` に記事生成・キーワード整理のスクリプト、
  `docs/` に参考資料、`output/` に生成した記事案を保存するワークフローが組める

目標ペース: 週2〜3記事 × 3ヶ月 = 30記事前後。X は毎日1〜3ポスト。

### ステップ3: 収益化と改善（3〜6ヶ月目）

- Search Console でインプレッションが出始めた記事を優先リライト
- 成果が出た記事の「型」を横展開
- X フォロワー1,000人を目安に、ポストからブログへの導線を強化

### 現実的なマイルストーン

| 時期 | 目標 | 状態 |
|---|---|---|
| 3ヶ月 | 初成果発生（数百〜数千円） | 記事30本、X 500フォロワー |
| 6ヶ月 | 月1〜3万円 | 検索流入が立ち上がる |
| 12ヶ月 | 月5〜10万円 | 稼げる記事の型が確立 |
| 24ヶ月〜 | 月30万円〜 | 外注化・横展開フェーズ |

「月2,000万」は情報商材販売者のポジショントークとして聞き流し、
まず月10万円を24ヶ月以内に作るのを本気の目標にするのが現実的。

### 守るべきルール（アカウント凍結・法的リスク回避）

1. **ステマ規制**（2023年10月〜）: PR案件・アフィリエイトリンクには「PR」「広告」表記必須
2. **Xの規約**: アフィリエイトリンクの直貼りスパム、自動化ツールでの大量投稿は凍結対象
3. **ASP規約**: 虚偽の体験談、誇大表現（「絶対稼げる」等）は提携解除
4. **景品表示法・薬機法**: 効果効能の断定表現はNG（特に美容・健康系）
5. **著作権**: 他人のコンテンツのAI言い換え転載は論外

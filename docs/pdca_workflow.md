# PDCA運用ワークフロー

投稿は手動、それ以外は自動。このループを回す。

```
┌─ PLAN ────────────────────────────────────────┐
│ Claude: learnings.md を読んで次バッチを企画    │
│ （P7プロンプト + 検証したい仮説を1つ入れる）   │
└──────────────┬────────────────────────────────┘
               ▼
┌─ DO ──────────────────────────────────────────┐
│ Claude: content/queue/ に投稿パッケージ生成    │
│ あなた: 画像+caption.txt+comment.txtで投稿     │
│         投稿したらClaudeに「post_00Xを投稿した」│
│         と伝える（Claudeがposted/へ移動・記録）│
└──────────────┬────────────────────────────────┘
               ▼
┌─ CHECK ───────────────────────────────────────┐
│ あなた: 投稿48時間後に下の報告フォーマットで   │
│         数値をClaudeに貼る                     │
│ Claude: performance_log.csv に記録し分析       │
└──────────────┬────────────────────────────────┘
               ▼
┌─ ACT ─────────────────────────────────────────┐
│ Claude: learnings.md を更新（仮説の検証/棄却） │
│         → 次のPLANに自動反映                   │
└───────────────────────────────────────────────┘
```

## あなたがやること（2つだけ）

### 1. 投稿する（1日1回、1〜2分）
1. `content/queue/post_XXX/img/` の画像を番号順にTikTokへアップ
2. `caption.txt` の中身をキャプションに貼る
3. 投稿直後に `comment.txt` の中身をコメントして自分でピン留め
4. Claudeに「post_XXX投稿した」と一言送る

### 2. 数値を報告する（投稿48時間後、1分）

TikTokのインサイト（アナリティクス）を見て、これをClaudeに貼る:

```
post_XXX 報告
再生数:
いいね:
コメント:
保存:
シェア:
フォロワー増:
DM件数:
プロフィール表示:
気づき（任意）:
```

## Claudeが自動でやること

- 数値を `analytics/performance_log.csv` に記録
- 投稿間の比較分析（伸びた/伸びない要因の仮説検証）
- `analytics/learnings.md` の更新（3本ごとに仮説見直し）
- 学びを反映した次バッチの生成（queueが3本を切ったら自動提案）
- フェーズ移行の判定（フォロワー1,000人→ASP登録フェーズへの移行提案）

## 運用ルール

- フェーズ1（フォロワー1,000人まで）: アフィリエイトリンクなし。投稿頻度は週4〜5本
- 投稿時間はまず19〜22時で固定し、データがたまったら時間も検証対象にする
- queueの投稿順は番号順が基本だが、learnings.mdの学びで入れ替えてよい

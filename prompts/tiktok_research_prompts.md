# TikTok成長リサーチ プロンプトテンプレート集

`tiktok-growth-research` スキルから利用する、再利用可能なプロンプト集。
`{{変数}}` を都度置き換えて使う。すべて `knowledge/tiktok_growth_knowledge.md` を前提知識として与えたうえで実行すること。

運用の前提: アフィリエイト導線は**DM誘導型**（動画→視聴者からDM→リンク返信）。ナレッジ§0・§5参照。

---

## P1. トレンドリサーチプロンプト

```
あなたはTikTok成長戦略のリサーチャーです。
ナレッジベースを前提に、直近1〜4週間で伸びているTikTokのトレンドを調査してください。

【調査対象】
- ジャンル/ニッチ: {{ニッチ / 未指定なら全般}}
- 対象市場: {{日本 / グローバル}}

【データソースの優先順位】
1. TikTok Creative Center（公式）— トレンド音源・ハッシュタグ・広告クリエイティブの実データ
2. 複数の独立した業界メディアで一致している情報
3. 単独ブログの情報（使う場合は [参考値] と明記）

【調査項目】
1. 伸びているフォーマット・企画パターン（具体例つき）
2. 伸びている音源の傾向（※Creative Centerで確認できた範囲。確認できない場合は「未確認」と書く。ブログの又聞きを実データのように書かない）
3. 伸びているハッシュタグ・検索キーワード
4. フックの型（冒頭0-3秒）の傾向
5. アフィリエイト/物販導線の組み込み方の実例（特にDM誘導・ソフトセルの事例）

【出力形式】
- 各項目に情報源URLと確度ラベル（[公式]/[複数ソース]/[参考値]）を併記
- 最後に「今週すぐ試せるアクション3つ」（うち1つはDM誘導導線に関するもの）
```

## P2. 競合・ベンチマーク分析プロンプト

```
以下のTikTokアカウント/動画を分析してください。

【重要な前提】あなたはTikTok動画を直接視聴できません。以下のいずれかを必ずユーザーから受け取ってから分析すること。足りなければ分析を始めずに依頼者へ要求する。
- 動画の書き起こし（セリフ・画面テキスト）
- 動画の構成メモ（何秒で何が起きるか）
- キャプション・ハッシュタグ・固定コメントのコピー
- 公開されている再生数・いいね・コメント数

対象: {{アカウント名 + 上記データ}}

分析観点（ナレッジの評価軸に沿う）:
1. フックの型（Contrarian Claim / Mistake Warning / List Tease / Product Showcase / その他）
2. 動画尺と構成（起承転結・ループ構造）
3. 保存・コメントを誘発する仕掛け
4. 収益導線の入れ方（プロフリンク / TikTok Shop / DM誘導）とPR表記の有無・位置
5. 投稿頻度・シリーズ化の有無

出力: 1〜5を表形式でまとめ、自アカウント（DM誘導型）に応用できる点を3つ提案する。
```

## P3. 企画・台本生成プロンプト（DM誘導型アフィリエイト）

```
以下の条件でTikTok動画の台本を3案作成してください。

商材/テーマ: {{商材名・特徴}}
ターゲット視聴者: {{年齢層・悩み・関心}}
狙うアクション: {{DM送信（デフォルト） / 保存 / プロフィール遷移}}
DMトリガーキーワード: {{視聴者にDMで送ってもらう合言葉（例:「表」「リスト」）}}
動画尺: {{15秒 / 30秒 / 60秒 / 90秒〜3分}}

制約:
- 冒頭0-3秒はナレッジの「フックの型」から1つ以上を明示的に使う
- 構成は HOOK → VALUE → LOOP/引き → CTA
- CTAは「コメントで◯◯」ではなく「DMで『{{キーワード}}』と送って」形式にする（TikTokはコメント→自動DM未対応のため）
- 動画単体で価値が完結し、DMには「個別化された+α」がある設計にする（出し惜しみだけの動画は完了率が落ちる）
- 商品紹介はソフトセル。直接的な売り込み口調は避ける
- 商材がコスメ・サプリ・健康食品の場合、薬機法上NGな効能表現（「痩せる」「治る」等）を使わない
- 「絶対」「必ず稼げる」「No.1」等の根拠なき断定表現を使わない（優良誤認）
- PR表記が必要な場合、キャプション冒頭の文言と動画内テキスト表示位置も提示する
- 各案に、視聴完了率が下がりそうなポイントと改善案を1つ添える

出力形式: 案ごとに「フック」「本編セリフ/構成」「CTA」「キャプション案（ハッシュタグ・PR表記込み）」「固定コメント案（DM誘導の再掲）」を分けて記載。
```

## P4. コンプライアンス&規約チェックプロンプト

```
以下のTikTok投稿案（台本・キャプション・DM返信文面）を、日本の法規制とTikTok規約の両面でチェックしてください。

対象:
{{台本・キャプション・DM文面}}

【A. ステマ規制（広告の明示）】
1. アフィリエイトリンク/成果報酬の有無と広告表示の有無
2. PR表記の位置（スクロールなしで視認できる冒頭か）
3. PR表記の視認性（サイズ・色・埋もれていないか）
4. 音声のみに依存していないか（画面テキストと併用か）
5. ブランドコンテンツ表示設定ONの要否

【B. 表示内容そのもの】
6. 優良誤認・有利誤認（「No.1」「最安」「絶対」「必ず」等の根拠なき断定、打消し表示の視認性）
7. 薬機法（コスメ・サプリ・健康食品の効能表現）
8. TikTok禁止カテゴリ該当性（医薬品・酒・ギャンブル・タバコ・不動産等）

【C. DM文面（DM誘導型の場合は必須）】
9. インバウンド起点か（こちらから先に送る文面になっていないか）
10. スパム判定リスク（無関係なプロモ・唐突なリンク・同一文面の大量送信に見えないか）
11. DMリンクに「アフィリエイトリンクである旨」の一言があるか
12. DM内の誇大表現・虚偽実績の有無

出力: 項目ごとにOK/NG/要修正を判定し、NG・要修正は修正後の文言まで提示する（指摘だけで終わらない）。
```

## P5. 週次レポート生成プロンプト

```
過去7日間の自アカウントのTikTok運用結果を要約してください。

インプット:
- 投稿一覧と再生数/完了率/保存数/コメント数/DM受信数/DM→リンククリック数/成約数: {{データ貼付}}

出力:
1. 伸びた投稿トップ3とその共通点（フォーマット/フック/CTA）
2. 伸びなかった投稿の共通点と改善仮説
3. ファネル分析: 再生→DM受信→クリック→成約の転換率と、最も詰まっている段階
4. ナレッジの評価軸のうち今週特に意識すべきもの1〜2個
5. 来週試す施策3つ（うち最低1つはDM導線の改善）
```

## P6. DM返信設計プロンプト（DM誘導型の中核）

```
以下の商材について、視聴者からDMが来たときの返信テンプレートを設計してください。

商材: {{商材名・アフィリエイトリンク先}}
DMトリガーキーワード: {{動画で案内した合言葉}}
想定される質問パターン: {{分かっていれば記載}}

設計要件:
1. キーワードDMへの初回返信文（お礼 + 動画の+α情報 + リンク + 「※アフィリエイトリンクです」の明示）
2. よくある質問トップ3への返信文
3. 商材が合わなそうな相手への返信文（無理に売らない。信頼残高を優先）
4. 返信してはいけないNGパターン（誇大表現・薬機法NG表現・断定の具体例）

制約:
- コピペ一斉送信に見えない、相手の質問に答える文脈の文面にする
- 短縮URLではなく遷移先が分かるURL/中間ページを案内する
- botで自動化する場合を想定し、人間味のある表現でも事実と異なる自動応答（「今確認しました」等）は入れない

出力: テンプレートごとに文面 + 使いどころを記載。
```

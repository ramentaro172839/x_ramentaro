# TikTok成長リサーチ プロンプトテンプレート集

`tiktok-growth-research` スキルから利用する、再利用可能なプロンプト集。
`{{変数}}` を都度置き換えて使う。すべて `knowledge/tiktok_growth_knowledge.md` の内容を前提知識として与えたうえで実行すること。

---

## P1. トレンドリサーチプロンプト

```
あなたはTikTok成長戦略のリサーチャーです。
以下のナレッジを前提に、直近1〜4週間で伸びているTikTokのトレンドを調査してください。

【調査対象】
- ジャンル/ニッチ: {{ニッチ（例: 食べ物・ラーメン / 未指定なら全般）}}
- 対象市場: {{日本 / グローバル}}

【調査項目】
1. 伸びているフォーマット・企画パターン（具体例つき）
2. 伸びている音源・BGMの傾向
3. 伸びているハッシュタグ・検索キーワード
4. フックの型（冒頭0-3秒でどう掴んでいるか）の傾向
5. アフィリエイト/物販導線がある場合、どう自然に組み込んでいるか（ソフトセルの実例）

【出力形式】
- 各項目を箇条書きで、根拠となる情報源URLを併記
- 最後に「今週すぐ試せるアクション3つ」をまとめる
```

## P2. 競合・ベンチマーク分析プロンプト

```
以下のTikTokアカウント/動画群を分析してください。
対象: {{アカウント名 or 動画URLリスト}}

分析観点（knowledge/tiktok_growth_knowledge.md の評価軸に沿うこと）:
1. フックの型は何か（Contrarian Claim / Mistake Warning / List Tease / Product Showcase / その他）
2. 動画尺と構成（起承転結・ループ構造の有無）
3. 保存・コメントを誘発する仕掛け
4. アフィリエイト/商品導線の入れ方とPR表記の有無・位置
5. 投稿頻度・シリーズ化の有無

出力: 上記1〜5を表形式でまとめ、自分のアカウントに応用できる点を3つ提案する。
```

## P3. 企画・台本生成プロンプト（アフィリエイト訴求あり）

```
以下の条件でTikTok動画の台本を3案作成してください。

商材/テーマ: {{商材名・特徴}}
ターゲット視聴者: {{年齢層・悩み・関心}}
狙うアクション: {{保存 / プロフィール遷移 / 商品リンククリック}}
動画尺: {{15秒 / 30秒 / 60秒 / 90秒〜3分}}

制約:
- 冒頭0-3秒は knowledge/tiktok_growth_knowledge.md の「フックの型」から1つ以上を明示的に使うこと
- 構成は HOOK → VALUE → LOOP/引き → CTA の順を守ること
- 商品紹介は「ソフトセル」（エンタメ/教育コンテンツに自然に溶け込ませる）にすること。直接的な売り込み口調は避ける
- PR表記が必要な場合、キャプション冒頭に入れる文言も別途提示すること（日本の景品表示法・ステマ規制対応）
- 各案について、想定される視聴完了率が下がりそうなポイントとその改善案を1つ添える

出力形式: 案ごとに「フック」「本編セリフ/構成」「CTA」「キャプション案（ハッシュタグ・PR表記込み）」を分けて記載。
```

## P4. コンプライアンスチェックプロンプト

```
以下のTikTok投稿案（台本・キャプション）が日本のステマ規制・景品表示法に照らして問題ないか確認してください。

投稿案:
{{台本・キャプション本文}}

チェック項目:
1. アフィリエイトリンク/成果報酬の有無と、それに対する広告表示の有無
2. PR表記の位置（スクロールなしで視認できる冒頭にあるか）
3. PR表記の視認性（フォントサイズ・色・埋もれていないか）
4. 音声のみでの言及に依存していないか（画面テキストと併用しているか）
5. TikTok側のブランドコンテンツ表示設定をONにする必要があるか

出力: 項目ごとにOK/NG/要修正と、NG・要修正の場合の具体的な修正文言を提示する。
```

## P5. 週次レポート生成プロンプト

```
過去7日間の自アカウントのTikTok運用結果を要約してください。

インプット:
- 投稿一覧と再生数/保存数/コメント数/プロフィール遷移数/リンククリック数: {{データ貼付}}

出力:
1. 伸びた投稿トップ3とその共通点（フォーマット/フック/CTA）
2. 伸びなかった投稿の共通点と改善仮説
3. knowledge/tiktok_growth_knowledge.md の評価軸のうち、今週特に意識すべきもの1〜2個
4. 来週試す施策3つ（うち最低1つはアフィリエイト導線の改善）
```

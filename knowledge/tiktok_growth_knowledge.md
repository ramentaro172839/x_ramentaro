# TikTok成長リサーチ ナレッジベース

最終更新: 2026-07-06（継続的に更新すること。情報は数ヶ月で古くなる前提で扱う）

TikTok全般のトレンド・成長メカニズムを、アフィリエイト収益化を見据えて整理したナレッジ。
`.claude/skills/tiktok-growth-research/SKILL.md` から参照される前提。

## 1. アルゴリズムの評価軸（2026年時点）

優先度が高い順:

1. **視聴完了率（Completion Rate）** — 最重要シグナル。2024年は50%が目安だったが、2026年はバイラルに乗るには70%以上が目安。
2. **冒頭1.5〜3秒の離脱率** — アルゴリズムは投稿後ごく短時間で「伸ばすかどうか」の一次判定を行う。ここで離脱されると再浮上しにくい（コールドスタート落ち）。
3. **保存数（Saves）** — 「あとで見返したい」シグナルとして「いいね」より重み付けが高い。ノウハウ・リスト系コンテンツが伸びやすい理由。
4. **コメント（特に初動1時間）** — 投稿直後1時間が「ゴールデンタイム」。自分でピン留めコメントを投稿し、質問を投げて会話を誘発すると初速が伸びる。
5. **視聴時間・リピート視聴（ループ再生）** — オチが分かっていても見返したくなる構成（ループ構成）は評価が高い。
6. **アカウントの専門性・ニッチ適合度** — 2026年はバズよりも「コミュニティ適合度（ニッチとの一致度）」が重視される。雑多な投稿より一貫したニッチのほうが伸びやすい。
7. **TikTok SEO（キャプション・音声内のキーワード）** — 検索流入対策として、キャプションや発話内容に検索されやすいキーワードを含める。

## 2. 伸びているコンテンツフォーマット

- **シリーズ化コンテンツ**: 「Part1/Part2/Part3」や週次テーマ企画。続きが気になる設計にすることで、フォロー率・再訪率が上がり、アルゴリズムも次のパートを既存視聴者に優先表示しやすい。
- **ロングフォーマットの台頭**: 15〜30秒の短尺一辺倒ではなく、1〜3分の「起承転結がある」動画も完了率が高ければ優遇される。短尺だけに縛られない。
- **凝縮された学び系（マイクロエデュケーション）**: 単純なライフハックではなく、ニッチな専門性 + ストーリーテリングを組み合わせた「短時間で濃い学び」コンテンツ。
- **Product/Outcome Showcase**: 冒頭2秒で完成品・ビフォーアフター・結果を見せる。説明不要で結果そのものが引きになる、フック効果が最も高い型。
- **リアル・飾らない系（Raw & Authentic）**: 過剰な編集より「素の実感」が刺さる傾向が継続。
- **オリジナル音源の優遇**: トレンド音源は引き続き有効だが、2026年はオリジナル音声にもアルゴリズムの後押しが強まっている。
- **ソフトセル（自然な商品紹介）**: 直接的な宣伝より、エンタメ・教育コンテンツに商品を自然に溶け込ませた投稿の方がエンゲージメントが約73%高いというデータがある。アフィリエイト動画で特に重要。

## 3. フック（冒頭0〜3秒）設計の型

動画の成否の8割は最初の3秒で決まる。以下の型を組み合わせる。

- **Contrarian Claim（逆張り主張）**: 「実は◯◯は間違っている」
- **Mistake Warning（失敗警告）**: 「これをやると損する」「知らないと損する◯◯」
- **List Tease（リスト予告）**: 「〇〇な人が絶対にやってる3つのこと」
- **Product/Outcome Showcase（結果先出し）**: 冒頭2秒で完成形・ビフォーアフターを見せる
- **Visual / Text / Sound の3点フック**: 視覚的インパクト＋画面テキストの煽り＋音（BGM/声のトーン）を同時に組み合わせるとさらに離脱を防げる

台本の基本構造:
```
HOOK（0-3秒: 上記の型のいずれか）
→ VALUE（引きを保ったまま価値提供・展開）
→ LOOP or 引き（オチを匂わせて最後まで見させる/続きを匂わせる）
→ CTA（保存・コメント・プロフ遷移・購入導線への誘導）
```

## 4. TikTok Shop / アフィリエイトの市場動向

- 2026年の米国TikTok Shop流通総額（GMV）予測は約234億ドル、世界では800億ドル超。前年比でほぼ倍増ペースの、世界で最も急成長しているコマースチャネル。
- コンバージョン率は従来ECの3〜6倍（TikTok Shop経由で平均4.7% vs 従来EC 2〜4%）。
- クリエイター向け平均コミッション率は上昇傾向（米国平均13.02%）。カテゴリにより5〜30%まで幅がある。高品質クリエイターへは20%前後が競争力のある水準とされる。
- 「ショッピングタグ付きコンテンツ」は専用のショッピングフィードに露出しやすく、追加配信が期待できる。
- 勝っているブランドは単発の「アフィリエイトキャンペーン」ではなく、**クリエイターエコシステム**（ニッチクリエイターとの継続的関係、成果報酬設計、オンボーディング整備、ROIトラッキング、長期リテンション）を構築している。

## 5. 日本国内の法規制（アフィリエイト運用で必須）

- **ステルスマーケティング規制**（景品表示法、2023年10月1日施行）は2026年現在も消費者庁の執行が活発。個人のアフィリエイターも対象になり得る。
- 成果報酬型リンク（アフィリエイトリンク）を貼る投稿は広告とみなされ、明示なしは景品表示法違反のリスクがある。
- TikTokでブランドコンテンツを投稿する場合は「ブランドコンテンツ表示」をONにし、キャプション冒頭に **#PR** または **#広告** を明記する。
- 運用フェーズは「表記があればOK」ではなく「一般消費者が“広告だ”と一目で認識できるか」が問われる段階に進んでいる。動画冒頭（スクロールなしで見える位置）に視認性の高いフォントサイズ・色でPR表記を配置すること。
- 音声のみの言及（口頭で「PRです」と言うだけで画面表示なし等）はリスクが残るため、**画面テキスト表示 + キャプション表記の二重掛け**が安全。

## 6. 投稿運用の実務

- 投稿直後1時間が「ゴールデンタイム」。自作自演のピン留めコメントで会話を誘発する。
- 投稿頻度・時間帯の一貫性はアカウントの専門性評価に寄与する。
- ハッシュタグは「バズワード羅列」より、TikTok内検索（TikTok SEO）で拾われるニッチキーワードを優先。
- KPIは再生数だけでなく「保存数」「完了率」「プロフィール遷移率」「リンククリック率（アフィリエイト導線）」まで追う。

## 0. 前提: このアカウントのアフィリエイト導線（DM誘導型）

本リポジトリの運用は「動画→視聴者からDMが来る→**DMでアフィリエイトリンクを返信する**」導線を採用する。
キャプションに外部リンクを貼れないTikTokの制約を回避でき、1対1の高意向ユーザーに直接届けられる。
詳細は §5「アフィリエイト導線設計」を参照。**すべての企画・台本はこの導線への接続を前提に設計する。**

## 1. アルゴリズムの評価軸（2026年時点）

優先度が高い順:

1. **視聴完了率（Completion Rate）** — 最重要シグナル。バイラルの目安は70%以上 [参考値]。
2. **冒頭1.5〜3秒の離脱率** — アルゴリズムは投稿後ごく短時間で「伸ばすかどうか」の一次判定を行うとされる（1.5秒説は[参考値]）。ここで離脱されると再浮上しにくい。
3. **保存数（Saves）** — 「あとで見返したい」シグナルとして「いいね」より重み付けが高い [複数ソース]。ノウハウ・リスト系が伸びやすい理由。
4. **コメント（特に初動1時間）** — 投稿直後1時間の初速が重要 [複数ソース]。投稿者自身が質問コメントを固定（ピン留め）して会話を誘発するのは正当なテクニック。
5. **視聴時間・リピート視聴（ループ再生）** — オチが分かっていても見返したくなるループ構成は評価が高い。
6. **アカウントの専門性・ニッチ適合度** — 2026年はバズよりも「ニッチとの一致度」重視 [複数ソース]。雑多な投稿より一貫したニッチが伸びる。
7. **TikTok SEO（キャプション・音声内のキーワード）** — 検索流入対策。

## 2. 伸びているコンテンツフォーマット

- **シリーズ化コンテンツ**: Part1/Part2/週次テーマ。フォロー率・再訪率が上がり、次パートが既存視聴者に優先表示されやすい。
- **ロングフォーマットの台頭**: 1〜3分の「起承転結がある」動画も完了率が高ければ優遇 [複数ソース]。
- **凝縮された学び系**: ニッチ専門性 × ストーリーテリングの「短時間で濃い学び」。
- **Product/Outcome Showcase**: 冒頭2秒で完成品・結果を見せる。フック効果が最も高い型とされる [参考値]。
- **Raw & Authentic**: 過剰編集より素の実感。
- **オリジナル音源の優遇**: トレンド音源も有効だが、2026年はオリジナル音声への後押しが強まっている [参考値]。
- **ソフトセル**: 直接的な宣伝より、教育/エンタメに商品を溶け込ませた投稿の方がエンゲージメントが高い（+73%という数字は[参考値]。傾向自体は[複数ソース]）。

## 3. フック（冒頭0〜3秒）設計の型

「成否の8割は最初の3秒」[参考値] だが、冒頭が最重要であること自体は[複数ソース]。

- **Contrarian Claim（逆張り主張）**: 「実は◯◯は間違っている」
- **Mistake Warning（失敗警告）**: 「これをやると損する」
- **List Tease（リスト予告）**: 「◯◯な人が絶対にやってる3つのこと」
- **Product/Outcome Showcase（結果先出し）**: 冒頭2秒で完成形・ビフォーアフター
- **Visual × Text × Sound の3点フック**: 同時に組み合わせて離脱を防ぐ

台本の基本構造:
```
HOOK（0-3秒） → VALUE（価値提供） → LOOP/引き → CTA（保存・コメント・DM誘導）
```

## 4. TikTok Shop / アフィリエイトの市場動向

- 2026年の米国TikTok Shop GMV予測は約234億ドル、世界800億ドル超 [参考値]。**米国市場のデータであり日本には直接適用できない**。日本のTikTok Shopは2025年開始で、機能・対象カテゴリ・アフィリエイト条件が米国と異なるため、利用前に日本版の最新要件を必ず確認する。
- コンバージョン率は従来ECの3〜6倍 [参考値]。
- クリエイター平均コミッション率は上昇傾向（米国平均13.02%、5〜30% [参考値]）。
- 勝っているのは単発キャンペーンではなく**クリエイターエコシステム**（継続関係・ROI追跡・長期リテンション）[複数ソース]。

## 5. アフィリエイト導線設計（DM誘導型が主軸）

### TikTokのリンク制約（導線設計の前提）
- 動画キャプションに外部リンクは貼れない。導線は実質 (a) プロフィールのリンク欄（lit.link等の中間ページ経由）、(b) TikTok Shop連携、(c) **DMでのリンク送付**、の3系統。
- 本アカウントは (c) DM誘導型を主軸とする。

### DM誘導型ファネルの設計
```
動画（価値提供 + 「詳細はDMで『◯◯』と送って」CTA）
→ 視聴者からDMが届く（インバウンド）
→ キーワードに応じてリンク + 補足情報を返信
→ 成約
```
- **必ずインバウンド（相手から先にDMが来る）を起点にする。** こちらから先に送るコールドDMはスパム判定・アカウント停止リスクが高い。
- CTAは「DMで特定キーワードを送ってもらう」形式にすると、後述の自動化とも接続でき、返信も定型化できる。
- DM返信は速度が印象を大きく左右する [複数ソース]。テンプレートを整備しておくべきだが、コピペ一斉送信に見える文面は避ける（§スパム対策参照）。

### プラットフォーム規約上のリスクと対策 [公式]
- TikTokコミュニティガイドラインは、DMでの「ランダムなテキスト、関連性のないプロモーション、またはリンク」をスパムとして禁止。違反はメッセージ削除→DM一時停止→反復で永久停止。
- 対策: (1) 相手の質問に answering する文脈でリンクを送る（無差別送付しない）、(2) 同一文面の大量送信を避ける、(3) 短縮URLより遷移先が分かるURL/中間ページを使う、(4) 医薬品・酒・ギャンブル・タバコ・不動産などTikTokのブランドコンテンツポリシー禁止カテゴリの商材を扱わない。
- DM利用は16歳以上 [公式]。相手のDM受信設定によっては相互フォローが必要な場合がある。

### DM自動化の現状（2026年7月時点）
- ManyChat等のTikTok DM自動化は**キーワードトリガー型**（ユーザーが特定ワードをDMすると自動返信）が利用可能。ビジネスアカウント必須。
- Instagramにある「コメント→自動DM」トリガーはTikTokでは**未対応**（開発中とされる）。よってCTAは「コメントで◯◯」ではなく「**DMで◯◯と送って**」にする。
- 自動化する場合も、応答が bot であることを偽らない・虚偽の実績を自動送信しない。

### DM誘導型と相性の良いコンテンツ（リサーチ結果）
- **リードマグネット型**: 「◯◯の比較表/テンプレ/リストが欲しい人はDMで『表』と送って」— 動画では要点だけ見せ、完全版をDMで渡す。保存数とDM数を同時に稼げる。
- **診断・相談型**: 「あなたの場合どれが合うかはDMで聞いて」— 1対1前提のDM導線と最も自然に噛み合う。
- **続き・限定情報型**: 「ここでは言えない詳細はDMで」— 引きは強いが煽りすぎると規約・景表法リスク。誇大にしない。
- 共通する設計原則: 動画単体で価値が完結しつつ、「個別化された+α」がDMにある状態を作る。動画が出し惜しみだけだと完了率が落ちる。

## 6. 法規制（アフィリエイト運用で必須）

### ステマ規制（景品表示法）[公式]
- 2023年10月施行、2026年現在も執行が活発。規制の名宛人は「表示内容の決定に関与した事業者（広告主）」だが、広告主案件を受けるアフィリエイターの表示も広告主経由で問題化するため、実務上は表記必須と考える。
- TikTokでは「ブランドコンテンツ表示」ON + キャプション冒頭に **#PR** / **#広告**。
- 運用フェーズは「表記があればOK」ではなく「一般消費者が明瞭に識別できるか」。動画冒頭のスクロールなしで見える位置に、視認性の高いサイズ・色で表示。音声のみに頼らず**画面テキスト + キャプションの二重掛け**。

### DMにも表示規制は及ぶと考えて運用する
- 消費者庁はSNSのDM・チャット経由の広告/勧誘の規制を検討中（2026年時点で議論進行中）[公式]。
- DMで送るリンクにも「アフィリエイトリンクである旨」を一言添えるのが安全（例: 「※アフィリエイトリンクです」）。
- DM文面でも誇大表現・虚偽の実績提示は景表法（優良誤認・有利誤認）の対象になり得る。

### 表示内容そのものの規制（表記だけでは足りない）
- **優良誤認・有利誤認**: 「No.1」「最安」「絶対」「必ず稼げる」等は根拠資料がなければNG。打消し表示の小ささも問題になる。
- **薬機法**: コスメ・サプリ・健康食品は効能効果の表現範囲が法定されている。「痩せる」「治る」「シミが消える」は原則NG。アフィリエイト主力ジャンルほど規制が厳しいことに注意。
- **特商法**: 自ら販売・勧誘の主体になる場合は表示義務が発生し得る。DM勧誘への適用拡大が議論中。
- **TikTok側の禁止カテゴリ**: 医薬品・酒・ギャンブル・タバコ・不動産等はブランドコンテンツ不可 [公式]。

## 7. 投稿運用の実務

- 投稿直後1時間がゴールデンタイム。投稿者コメントの固定で会話を誘発。
- DM誘導CTAを使う動画では、固定コメントにも「DMで『◯◯』と送ってね」を再掲する。
- ハッシュタグはバズワード羅列よりTikTok SEOで拾われるニッチキーワード優先。
- KPI: 再生数 / 完了率 / 保存数 / **DM受信数 / DM→リンククリック率 / 成約率**。DM誘導型では後半3つが本丸。

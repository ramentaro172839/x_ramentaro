# SNSアフィリエイト・プレイブック

X(旧Twitter)を中心としたSNSアフィリエイトで「見込み客を集めて売る」ための基本戦略。
Threads・TikTok・Instagram・YouTubeにも応用可能。

## 大原則

**フォロワーは「数」ではなく「質(見込み客)」で集める。**

- 相互フォロー・ブルバでの数集めは時間の無駄。興味のない人は何を紹介しても買わない。
- フォロワー4,000人でも売れない人と、1,000人で毎月成果を出す人の差は
  「見込み客を集めているか」「信頼を積み上げてから売っているか」の2点だけ。
- 信頼のないまま売るのは、グラグラの土台にビルを建てるのと同じ。

## 第1章: 売れない人のNG行動(やらないことリスト)

1. **フォロワーを数で集める** — 相互フォロー・ブルバ100%は禁止。
2. **信頼構築前にアフィリンクを貼る** — 理想は運用開始から最低3ヶ月は売り込まない。
   - 例外: 「今まさにリアルタイムで体験中」なら初日から実況型発信OK(それ自体がストーリーになる)。
   - DMで相談が来たら個別ヒアリング→訴求はOK。
   - ただし運用3ヶ月未満での公式LINE誘導はNG(業者っぽさで信頼を失う)。
3. **ストーリーなしの情報だけ発信** — 「おすすめ5選」等の機能的価値ポストは読まれない。
   読者が反応するのは情緒的価値(体験談・ストーリー)。インプ稼ぎ目的の情報ポストと、
   売るためのストーリーポストは役割を分けて使う。
4. **ジャンルと無関係な案件紹介** — 1アカウント1〜2ジャンルに絞る。
   親和性があれば跨ぎOK(例: 転職×美容 =「面接は見た目が命」)。
5. **低単価ジャンルで消耗** — Amazonアソシエイト等の数十円案件は労力対効果が悪すぎる。
   個人に薄利多売は不可能。高単価一択。

## 第2章: 売るための手順(DRM 6ステップ)

前提: ASP(A8.net・もしもアフィリエイト・アフィリエイトB等)に無料登録し、
発信ジャンルに合う案件を確保しておく。

### 高単価おすすめジャンルと単価目安

| ジャンル | 1件あたり報酬 |
|---|---|
| 転職・就職 | 8,000〜50,000円 |
| 金融・クレジットカード | 5,000〜20,000円 |
| 保険 | 10,000〜50,000円以上 |
| プログラミング・オンラインスクール | 50,000〜100,000円以上 |
| 婚活・マッチングアプリ | 5,000〜20,000円 |
| FX・投資 | 10,000〜50,000円以上 |
| 脱毛・美容医療 | 10,000〜30,000円 |
| 不動産 | 10,000〜100,000円以上 |

季節に合わせて扱う案件を変えるのも有効(→ `knowledge/account-profile.md` の案件リストで管理)。

### 6ステップ

1. **目的の教育** — 「この人みたいになりたい」と思わせる。成功した姿・悩みが解決した未来を見せる。
2. **信用の教育** — 日常ポストで信頼と親近感を積む。ジャンル外の話でもOK。
   実績・売上の提示で「この人は何か持っている」と思わせるのも有効。**この段階でリンクは貼らない。**
3. **問題点の教育** — 読者が心に抱えるモヤモヤを代弁・言語化する。
   「この人は自分をわかってくれている」と感じさせる。仮想敵の設定(ポジション取り)も有効。
4. **手段の教育** — ここで初めて解決策として案件を紹介する。「これが一番いいと思います」と自分の言葉で。
5. **投資の教育** / 6. **行動の教育** — 「無料」「登録だけ」「5分でできる」「合わなければやめればいい」で
   行動のハードルを下げ、背中を押す。

- 1つのポストに複数ステップが混ざることもある(例: 問題点+手段)。
- **すべてのポストは「このポストの目的は何か」を明確に答えられる状態で作る。**
- このプロセスに近道はない。順番を守ることが最速ルート。

## 実績がない時期のポスト作成(時系列ずらしの4型)

枕言葉: 「もし過去に戻れるなら」「もし人生をやり直せるなら」「当時の自分に伝えるとしたら」
「今、〇〇を仕込んでるんだけど」「年収〇〇万稼ぐ知り合いに聞いたんだけど」

1. **過去の自分に戻る型** — 「あの頃の自分に伝えたいのは〜」
2. **知り合い設定型** — 「先輩が〇〇を使って年収100万上がったらしい」
3. **子供への伝言型** — 「もし子供が〇〇したいと言ったら、これだけは教えたい」
4. **切り口変え型** — 今やっていることを別の角度から書く「今とある案件に取り組んでるんだけど〜」

具体例文は `knowledge/post-templates.md` を参照。

⚠️ **運用上の注意(独自追加)**: 架空の収益額や実在しない体験を事実として断定するポストは、
景品表示法・ステマ規制(アフィリエイトポストのPR表記義務)やアカウント凍結のリスクがある。
「もし〜なら」「〜としたら」の仮定形フレーミングを優先し、金額・実績は実際のものを使うこと。
アフィリンクを含むポストにはPR表記を入れる。

## 初期フェーズを突破する2つの戦略

1. **トレンド×自ジャンル** — アルゴリズムはトレンドワードを優遇する。
   旬のネタ(現在はAI系が強い)を自ジャンルと掛け合わせる。
   例: 「Claude Codeで職務経歴書を作ったら褒められた」「マッチングアプリのプロフをAIに作らせたらいいね爆増」
2. **大手アカウントへの積極リプライ** — アカウントパワーの強い相手からリプが返ると上位表示され、
   露出が跳ね上がる。ありきたりなリプではなく、クスッと笑える・ためになるリプで返信率を上げる。
   AI出力をそのまま貼るのはNG(AIっぽさがバレると信頼を失う)。必ず自分の言葉でアレンジ。

初期は「巨人の肩に乗る」割り切りで。伸びて追い抜いたら関わらなくていい。

## 信頼を貯めるコツ

- 初期は絶対に上から目線のポストをしない。フラットなポジションで「応援したくなる」アカウントを目指す。
- 頑張っている過程を見せて「この人を追いかけたい」と思わせる(実況型・進捗報告型)。
- 「AIで診断ツールを作ってみた」のようにツール紹介の体でさりげなくリンクを送る手法も有効。

## 0→1達成後の展開

- 月10件ほど成約できれば、ASPに特別単価を申請して通る可能性が高い。
- 展開先: ①実績をもとにコンテンツ制作 ②コンサル・サポート提供 ③アカウント複数展開 ④高単価案件(1件20万〜150万円)へ移行。
- 低単価でも高単価でもやることは同じ。売る感覚を掴んだら単価を上げるだけで収益は10倍にできる。

## 成果を出すためにやめる7つのこと

1. 低単価のアフィリエイト
2. 個別コンサル販売(時間を売ると発信が止まる)
3. 教材購入を迷う時間(迷ったら即決。時間の損失の方が痛い)
4. 目的のない友達作り(友達より仲間。馴れ合い不要)
5. 万人受け(ターゲットをたった一人に絞って書く)
6. 全部自分でやること(苦手は人に任せる)
7. 完璧主義(70%の完成度で出して、反応を見て直す)

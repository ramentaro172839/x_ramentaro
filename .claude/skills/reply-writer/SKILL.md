# reply-writer: リプ職人

初期フェーズの最重要戦略「大手アカウントへの高精度リプライ」を支援するスキル。
アカウントパワーの強い相手からリプが返ってくると上位表示され、露出とフォロワー獲得に直結する。
初期アカウントはリプの精度が勝負を分ける。

## 手順

1. **必ず先に読む**: `knowledge/account-profile.md`(ペルソナ・口調・ジャンル・リプ先リスト)。
2. **対象ポストを受け取る**: ユーザーが貼ったポスト本文を分析する(話題・トーン・相手のキャラ)。
3. **リプ案を3つ生成**。狙いはそれぞれ変える:
   - **ウィット型**: クスッと笑える切り返し。大喜利ではなく、相手が思わず返したくなる軽妙さ
   - **価値提供型**: ためになる一言・補足・実体験。相手のポストを引き立てる
   - **共感+引き型**: 深い共感を示しつつ、自分の視点や続きが気になる一言を添える
4. **セルフチェック**(全案に適用):
   - [ ] ありきたりなリプ(「勉強になります!」「有益です!」等)になっていないか
   - [ ] 相手のポストをちゃんと読んだことが伝わる内容か
   - [ ] 上から目線・マウントになっていないか(フラットなポジション)
   - [ ] AIっぽい文章になっていないか(整いすぎ・絵文字過多・定型文臭)
   - [ ] アカウントのペルソナ・口調と一致しているか
5. **注意書きを添える**: 「そのまま貼らず、必ず自分の言葉で少しアレンジしてから使う」ことを毎回リマインドする(AI出力とバレた瞬間に信頼を失うため)。

## 心得

- 目的は「返信をもらうこと」。返信がもらえれば上位表示され、多くの人の目に留まる。
- 初期だけの割り切り(巨人の肩に乗る)。伸びたら卒業してよい。
- リプ先の選定は account-profile のリプ先リストを使い、リストが薄ければ拡充を提案する。

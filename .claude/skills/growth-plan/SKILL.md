# growth-plan: フェーズ診断と運用プラン

アカウントの現在地を診断し、DRM戦略に沿った具体的な行動計画に落とすスキル。

## 手順

1. **必ず先に読む**: `knowledge/account-profile.md` と `knowledge/affiliate-playbook.md`。
2. **フェーズ診断**: 運用開始日・フォロワー数・成約状況から現在フェーズを判定し、account-profile のフェーズ判定を更新する。

| フェーズ | 状態 | やること | やらないこと |
|---|---|---|---|
| 初期(〜3ヶ月) | 信頼構築期 | 信用ポスト、実況、トレンド×ジャンル、大手へのリプ | リンク訴求、公式LINE誘導、上から目線 |
| 実況型例外 | リアルタイム体験中 | 初日から実況発信、DM相談への個別対応 | 公式LINE誘導(3ヶ月未満) |
| 教育期(3ヶ月〜) | 信頼あり・販売前 | 目的・信用・問題点の教育を回す | 焦ったリンク連投 |
| 販売期 | 見込み客が育った | DRM全ステップ、手段・投資・行動ポスト | 教育を止めて売り込みだけにすること |
| 0→1達成後 | 成約が出た | 横展開、月10件→特別単価申請、高単価案件へ移行 | 低単価での消耗継続 |

3. **週次プランを作る**(例):
   - ポスト: 各ステップの配分(初期なら 信用5:実況3:トレンド2、販売期なら 教育6:訴求2:日常2 など)
   - リプ: 1日あたりの本数と対象アカウント(account-profile のリスト)
   - 素材集め: 実体験ストックへの追記
4. **伸び悩み診断**: 「伸びない」「売れない」相談には playbook の第1章NG行動チェックリストを当てる:
   - フォロワーを数で集めていないか
   - 信頼構築前にリンクを貼っていないか
   - 情報だけでストーリーがないポストになっていないか
   - ジャンル外の案件を紹介していないか
   - 低単価ジャンルで消耗していないか
5. **プラン提示後**: account-profile の KPI・フェーズを更新する。

## 原則

- 順番を守ることが最速ルート。フェーズを飛ばす提案はしない。
- 完璧主義より70%で出して修正。「まず今日やる1つ」を必ず具体的に示す。
- 万人受けを狙わない。ターゲットたった一人を再確認してからプランを作る。

# product-picker: 案件選定コンシェルジュ

「何を売ればいいかわからない」を解決するスキル。
アカウントのコンセプト・経歴・趣味・思考をヒアリングし、適切なアフィリエイトジャンルと案件タイプを提案する。

## 手順

1. **必ず先に読む**: `knowledge/account-profile.md` と `knowledge/affiliate-playbook.md` の「高単価おすすめジャンル」表。
2. **ヒアリング**(account-profile に情報があれば省略):
   - 発信ジャンル・コンセプト
   - 本人の経歴・実体験(語れるストーリーがあるジャンルが最優先)
   - 趣味・興味・得意分野
   - ターゲット読者の悩み
3. **診断基準**(優先順):
   1. **実体験があるか** — 情緒的価値ポストの原料になる。体験のあるジャンルが最強
   2. **高単価か** — 1件5,000円以上が最低ライン。個人に薄利多売は不可能、高単価一択
   3. **発信ジャンルと一致するか** — 無関係な案件は信頼を崩す。親和性があれば跨ぎ可(例: 転職×美容)
   4. **季節性** — 狙い目の月がある案件はカレンダー管理(account-profile の案件リストの「狙い目の月」列)
4. **提案フォーマット**:
   - 第1候補〜第3候補のジャンルと理由
   - 各ジャンルの単価目安(playbook の表から)
   - 対応するASP(A8.net / もしもアフィリエイト / アフィリエイトB 等)
   - そのジャンルで最初に作るべきポストの方向性(1行)
5. **決定したら**: `knowledge/account-profile.md` の案件リストに追記する。

## 判断の原則

- Amazonアソシエイト等の数十円案件は提案しない(消耗するだけ)
- 「報酬が高いから」だけでジャンル外案件を勧めない(信頼が先、単価は次)
- 1アカウント1〜2ジャンルに絞る
- 0→1達成後、月10件成約が見えたら特別単価申請を提案する

# post-writer: DRMポスト生成

アフィリエイトで売るためのポストを、DRM(ダイレクト・レスポンス・マーケティング)の6つの教育要素に沿って生成するスキル。

## 手順

1. **必ず先に読む**: `knowledge/account-profile.md`(アカウント設定・フェーズ・案件・実体験ストック)と `knowledge/affiliate-playbook.md`(戦略の全体像)。
2. **フェーズ確認**: account-profile のフェーズ判定に従う。
   - 初期(3ヶ月未満)なら手段・投資・行動ポスト(リンク訴求)は作らない。信用・実況・問題点ポストのみ提案し、理由を一言添える。
   - 実況型例外が適用されているなら、リアルタイム体験の実況ポストは初日からOK。
3. **目的を決める**: どのステップのポストかをユーザーに確認するか、依頼内容から判断して明示する。
   1. 目的の教育(理想の姿を見せる)
   2. 信用の教育(日常・実績で信頼を積む/リンク禁止)
   3. 問題点の教育(悩みの代弁・仮想敵)
   4. 手段の教育(案件を初めて紹介)
   5. 投資の教育 / 6. 行動の教育(無料・簡単・すぐできる、でハードルを下げる)
4. **型を選ぶ**: `knowledge/post-templates.md` から該当ステップ×ジャンルの型を選び、アカウントのペルソナ・口調・実体験ストックに合わせて書き下ろす。テンプレの丸パクリはしない(陳腐化・独自性喪失)。
5. **3案出す**: トーン違い(ストレート/エモ/軽口)で3案生成し、それぞれ「このポストの目的」を1行で付記する。
6. **セルフチェック**(全案に適用):
   - [ ] 情緒的価値(ストーリー・感情)が入っているか。機能的価値だけになっていないか
   - [ ] ターゲットたった一人に向けて書いているか(万人受けは誰にも刺さらない)
   - [ ] 上から目線になっていないか(特に初期)
   - [ ] 140字に収まるか(長文ポストにする場合は意図を明示)
   - [ ] アフィリンクを含むならPR表記があるか
   - [ ] 実在しない体験・金額を事実として断定していないか(実績がない場合は「もし過去に戻れるなら」等の仮定形か、実体験ストックを使う)

## 実績がない時期の型(時系列ずらし)

`knowledge/post-templates.md` の4型を使う: ①過去の自分に戻る型 ②知り合い設定型 ③子供への伝言型 ④切り口変え型。
仮定形フレーミングを優先し、具体的な金額の捏造はしない。

## トレンド掛け合わせ

インプ狙いのポストは、旬のトレンド(現在はAI系)×自ジャンルの切り口を使う。
`knowledge/post-templates.md` の「トレンド×ジャンルの切り口例」参照。
